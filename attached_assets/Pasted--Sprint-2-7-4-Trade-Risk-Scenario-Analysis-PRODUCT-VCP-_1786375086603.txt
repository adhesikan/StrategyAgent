======================================================================
OBJECTIVE
======================================================================

Build a reusable deterministic risk engine that takes:

TradeRiskScenarioInput
        +
Selected Contract Research Candidate
        +
Current Structure Metrics
        +
Research Thesis
        +
Planning Constraints
        +
Underlying Reference Price
        +
Option Quotes / Greeks
        +
Event Context
        +
Volatility Context
        ↓
TradeRiskScenarioResult

The engine should answer:

- What is the structure's current economic profile?
- What is the maximum loss if mathematically defined?
- What is the maximum gain if mathematically defined?
- What is the breakeven?
- How does the structure react to changes in underlying price?
- How does time decay affect it?
- How does implied volatility expansion/contraction affect it?
- What are the net Greeks?
- What happens near earnings/events?
- How sensitive is this structure to liquidity and stale quotes?
- What assumptions and limitations matter?

It must NOT answer:

"Should I place this trade?"

======================================================================
4. MAX LOSS
======================================================================

Calculate max loss ONLY where mathematically valid.

Examples:

Long Call:
premium paid

Long Put:
premium paid

Bull Call Spread:
net debit

Bear Put Spread:
net debit

Credit Vertical:
spread width - net credit

Iron Condor:
max wing width - net credit, adjusted correctly if wings differ

Iron Butterfly:
defined structure math

Covered Call:
underlying downside remains substantial; max loss is NOT just option premium

Cash-Secured Put:
substantial downside to zero less premium

Protective Put:
bounded downside depending on put strike + premium

Collar:
calculate based on stock + put + call structure

Calendar / Diagonal:
do not claim simple fixed max loss/max gain unless mathematically valid.

If no clean closed-form max loss exists:

maxLoss.available = false

with explanation.

Never fabricate.

======================================================================
5. MAX GAIN
======================================================================

Calculate only where mathematically defined.

Examples:

Debit Vertical:
spread width - debit

Credit Vertical:
credit

Covered Call:
finite upside due to call strike plus stock basis assumptions

Cash-Secured Put:
premium is max option-side gain

Long Call:
theoretically unlimited upside

Long Put:
bounded by underlying reaching zero

Iron Condor:
net credit

Calendar/Diagonal:
often path/volatility-dependent

For unlimited:

maxGain.type = UNLIMITED

Do not convert to arbitrary number.

For path-dependent:

maxGain.type = PATH_DEPENDENT

with explanation.
