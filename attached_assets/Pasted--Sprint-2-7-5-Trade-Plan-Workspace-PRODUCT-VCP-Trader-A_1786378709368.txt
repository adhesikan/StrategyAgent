======================================================================
CORE ARCHITECTURE CONTRACT
======================================================================

Research answers:

WHAT deserves investigation?

Goals answer:

WHICH research matters to the user?

Portfolio Intelligence answers:

HOW the research relates to current exposure?

Trade Planning Foundation answers:

HOW the thesis could potentially be expressed?

Equity Planning answers:

HOW an equity research scenario could be structured.

Options Strategy Matching answers:

WHICH options strategy families are structurally compatible.

Options Contract Research answers:

WHICH contracts / expirations / strikes are worth researching.

Trade Risk & Scenario Analysis answers:

WHAT the economic/risk consequences of a selected structure look like.

Trade Plan Workspace answers:

HOW do we assemble all of that evidence into one persistent,
user-reviewed research plan?

Execution remains separate.

======================================================================
OBJECTIVE
======================================================================

Build a canonical Trade Plan Workspace that allows a user to:

1. Start from an existing qualified research candidate.
2. Review the authoritative research thesis.
3. Attach goal context if relevant.
4. Attach portfolio context if relevant.
5. Select an existing planning expression.
6. Review equity or options planning output.
7. Review risk/scenario analysis.
8. Record user notes.
9. Record monitoring criteria.
10. Save the plan.
11. Reopen the plan later.
12. Track plan status/history.
13. Compare current evidence with evidence at plan creation.
14. Continue research without re-entering context.

The key user question is:

"What is the complete research plan I created around this candidate?"

NOT:

"Should I place this trade?"

======================================================================
4. STATUS SEMANTICS
======================================================================

DRAFT:

User is still assembling/reviewing research plan.

RESEARCH_COMPLETE:

User has reviewed the available research, selected planning structure,
and saved the plan.

MONITORING:

User wants to monitor research conditions over time.

ARCHIVED:

No longer active.

INVALIDATED:

Only if current authoritative research evidence has crossed a documented
thesis invalidation condition.

Do NOT mark INVALIDATED merely because price moved adversely.

Use canonical invalidation evidence.
