Fix false ticker extraction in VCP Trader Ask AI recommendation and analysis routing.

OBSERVED PRODUCTION BUG

The user asked:

"Find a trade under $500 max loss"

The application extracted these ticker symbols:

- UNDER
- MAX
- LOSS

The UI displayed those tokens as ticker chips, and the AI narrative analyzed "the ticker UNDER" and "the ticker MAX."

This is incorrect.

The request contains no ticker. It is a market-wide recommendation request with:

- maxRiskDollars: 500
- numberOfIdeas: 1
- no symbol constraint

==================================================
3. CONTEXT-AWARE EXTRACTION
==================================================

Prioritize symbol extraction from:

1. prefixed ticker syntax such as $NVDA
2. explicit "ticker" or "symbol" language
3. known analysis/trade grammar:
   - Analyze NVDA
   - Find a trade for META
   - How does BA look?
4. validated existing symbol lookup, if available

For broad requests such as:

- Find a trade under $500 max loss
- Find an options trade
- What should I trade today?
- Find three bullish trades
- Find an income opportunity

return no symbol.

Do not ask for a symbol when the recommendation engine supports market-wide searches.

==================================================
4. PARSING ORDER
==================================================

Parse constraints before symbol extraction where useful.

For:

"Find a trade under $500 max loss"

recognize:

- "under $500"
- "max loss"
- maxRiskDollars = 500

Then exclude those consumed words from symbol consideration.

Similarly handle:

- under $300 risk
- maximum loss of $1,000
- risk no more than $250
- within a $500 budget

==================================================
5. RESPONSE AND UI SAFETY
==================================================

When no valid symbol exists:

- do not render ticker badges
- do not add symbol-specific market context
- do not ask OpenAI to analyze uppercase tokens
- invoke recommend_trade_strategy as a market-wide request
- let MCP select candidate symbols

The narrative must never discuss a token as a company unless it came from a validated symbol field.

==================================================
6. DEFENSE IN DEPTH
==================================================

Before calling symbol-specific tools, validate the extracted symbol again.

Reject known reserved-language tokens locally.

When the request is market-wide, ensure:

{
  symbol: undefined,
  maxRiskDollars: 500
}

is sent to recommend_trade_strategy.

Do not convert an absent symbol into an empty string or an arbitrary token.
