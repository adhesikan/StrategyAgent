Implement Recommendation Experience 2.0 for VCP Trader.

IMPORTANT

Do NOT modify:

- recommendation algorithms
- ranking algorithms
- scanner algorithms
- risk calculations
- MCP
- Trade Builder
- broker execution

This sprint is purely about presenting deterministic recommendation results in a professional trading decision-support interface.

Everything must remain additive.

Do not commit, push or deploy automatically.

----------------------------------------------------------
GOAL
----------------------------------------------------------

A trader should understand the recommendation in under 5 seconds.

The recommendation should become the primary artifact.

The GPT narrative should support it—not compete with it.
