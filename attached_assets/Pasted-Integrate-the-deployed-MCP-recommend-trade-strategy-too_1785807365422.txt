- Find a credit spread

- Find a cash-secured put

Route these to recommend_trade_strategy.

C. COMBINED INTENTS

Examples:

- Analyze NVDA and recommend a trade

2. recommend_trade_strategy

Return both sections without blending their scores or verdicts.

D. EDUCATION INTENTS

Examples:

- What is a credit spread?

E. MIXED EDUCATION + SEARCH

==================================================
8. OPENAI ROLE
==================================================

OpenAI may explain the structured recommendation.

It must not:

- change the verdict
- invent a symbol
- invent a contract
- invent premium or Greeks
- invent probability of profit
- present estimated/mock output as live
- turn WATCH into a trade
- override NO_TRADE
- recommend covered calls without verified holdings
- create bearish evidence when MCP found none

If OpenAI fails after MCP succeeds:

- render the recommendation cards
- use a concise deterministic server-generated summary
- do not discard the MCP result

ESTIMATED_OPTIONS:

- Save/Watch

STOCK:

Trade Builder only if fresh, actionable, and risk-complete.

WATCH / NO_TRADE / UNSUPPORTED:

No Trade Builder.

Never open Trade Builder automatically.
