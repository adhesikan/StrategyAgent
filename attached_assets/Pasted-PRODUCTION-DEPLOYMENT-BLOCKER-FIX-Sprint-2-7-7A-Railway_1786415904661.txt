============================================================
CONFIRMED RAILWAY FAILURE
============================================================

Railway/Nixpacks runs:

npm ci
npm run build
npx tsx script/migrate.ts && npm run start

The deployment failed during:

npm ci

Exact error:

npm error code ENOTFOUND
npm error syscall getaddrinfo

request to:

http://package-firewall.replit.local/npm/playwright-core/-/playwright-core-1.62.1.tgz

failed because Railway cannot resolve:

package-firewall.replit.local

This indicates package-lock.json contains one or more Replit-local
package-firewall resolved URLs.

We previously fixed this class of problem for other packages.
