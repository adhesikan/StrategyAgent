hidden behind the fixed global navigation and market-data banner.

The screenshot indicates:

- the drawer begins at the top of the viewport;
- the global navbar and data-source banner render above it;
- the assistant title/header area is clipped;
- the X close button is likely present in the hidden header region;
- only the research-question list is visible below the banners.

This is a focused layout and accessibility fix only.

Do not add features.
Do not change /api/ask.
Do not change assistant logic, prompts, backend context, broker logic, Workspace
sections, database, MCP, or business logic.

====================================================================
2. DEFINE ONE SHARED TOP OFFSET
====================================================================

Determine the combined visible height of:

- global application navbar;
- market-data/status banner.

Do not scatter hardcoded offsets across components.

Prefer one shared CSS variable or layout token, for example:

--app-shell-top-offset

Example only:

:root {
  --app-shell-header-height: 40px;
  --app-shell-banner-height: 44px;
  --app-shell-top-offset:
    calc(var(--app-shell-header-height) + var(--app-shell-banner-height));
}

Use the actual current layout values.

If the banner is conditional, derive the offset from the real rendered layout or expose
an existing layout variable rather than assuming it is always present.

====================================================================
3. POSITION THE DESKTOP DRAWER BELOW THE HEADER
====================================================================

Desktop assistant drawer should use:

position: fixed;
top: var(--app-shell-top-offset);
right: 0;
bottom: 0;

or equivalent Tailwind/CSS.

Its height should be:

calc(100dvh - var(--app-shell-top-offset))

Prefer 100dvh over 100vh where supported.

Do not use:

top: 0;
height: 100vh;

for the desktop drawer when a fixed global header exists.

Requirements:

- assistant title and close button fully visible;
- drawer does not overlap the navbar;
- drawer does not overlap the market-data banner;
- drawer body scrolls internally;
- input composer remains visible at the bottom;
- Workspace behind it remains positioned correctly.

====================================================================
