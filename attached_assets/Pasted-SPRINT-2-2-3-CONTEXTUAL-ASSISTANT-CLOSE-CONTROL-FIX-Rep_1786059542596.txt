2. ADD A PERMANENT VISIBLE CLOSE BUTTON
====================================================================

Add an explicit close button in the assistant header.

Desktop placement:

- top-right corner of the drawer
- inside the visible panel
- always present while the drawer is open

Mobile placement:

- top-right of the bottom-sheet header
- large enough for touch

Recommended structure:

<header className="...">
  <div>
    <h2>Ask VCP AI</h2>
    <p>Contextual research assistant for {symbol}</p>
  </div>

  <button
    type="button"
    aria-label="Close contextual research assistant"
    onClick={onClose}
  >
    <X />
  </button>
</header>

Requirements:

- use the existing icon library;
- minimum touch target approximately 40×40 px;
- visible hover state;
- visible focus ring;
- sufficient contrast in dark mode;
- no reliance on color alone;
- button must remain visible while the assistant content scrolls;
- header may be sticky inside the drawer if needed.
