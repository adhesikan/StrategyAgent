====================================================================
PRIMARY OBJECTIVE
====================================================================

Build an Institutional Intelligence feature that helps a self-directed investor
understand publicly reported institutional participation in a company.

Initial authoritative source:

SEC Form 13F reported holdings.

Optional supporting source:

Existing Twelve Data fundamental/reference endpoints, but only after entitlement,
coverage, cost and licensing are verified against the current subscription.

The user should be able to answer:

1. How many reporting 13F managers disclosed a position?
2. Did aggregate reported shares increase or decrease quarter over quarter?
3. Which reporting managers disclosed the largest positions?
4. How concentrated are the reported holdings among the largest managers?
5. Which managers initiated, increased, reduced or exited disclosed positions?
6. How old is the information?
7. What limitations apply to the data?
8. Does this institutional context support, remain neutral toward, or weaken the
   current research thesis under transparent deterministic rules?

Do not present 13F filings as real-time institutional flow.

Do not describe the result as complete institutional ownership unless the data and
calculation genuinely support that claim.

NON-NEGOTIABLE ACCURACY PRINCIPLES
====================================================================

- 13F Reported Holdings
- Reporting Managers
- Reported Shares
- Reported Market Value
- Quarter-over-Quarter Change
- Filing Date
- Period of Report
- Publicly Reported Institutional Position
- Reported Holder Concentration
- Data Through [quarter-end date]

Avoid unless independently supported:

- Total Institutional Ownership
- Institutions Own X% of the Company
- Smart Money Is Buying
- Institutional Flow Today
- Current Institutional Position
- Real-Time Accumulation
- Institutions Are Accumulating Now
- Strong Buy
- Institutional Confirmation

Important limitations must remain visible:

- Form 13F is periodic and delayed.
- The position reflects the period-of-report date, not necessarily the filing date.
- Filings may be amended.
- Form 13F does not provide a complete picture of all institutional activity.
- Short positions are not represented as ordinary long holdings.
- Put/call entries must not be mixed into common-stock share totals.
- Reported holdings may have changed after quarter end.
- Source filings may contain filer-supplied inaccuracies.

Never imply that institutional participation predicts future returns.

====================================================================
SEC ACCESS REQUIREMENTS
====================================================================

Follow SEC fair-access practices.

All SEC requests must:

- include a descriptive User-Agent identifying the application and contact email;
- use a low bounded request rate;
- use retries with backoff for retryable failures;
- honor HTTP errors and rate limits;
- use caching;
- avoid repeated downloads of unchanged quarterly files;
- avoid concurrent request storms;
- never bypass SEC access controls.

Add configuration such as:

SEC_USER_AGENT="VCP Trader AI contact@example.com"

Do not hardcode a personal email in source code.

If SEC_USER_AGENT is absent:

- disable SEC ingestion;
- emit a clear safe configuration error;
- keep the existing placeholder/unavailable state;
- do not issue anonymous high-volume requests.

====================================================================
AMENDMENT AND DUPLICATION POLICY
====================================================================

Define a deterministic policy for amendments.

Requirements:

- retain original and amended filings for auditability;
- determine which filing version is considered effective;
- avoid double-counting an original filing and its amendment;
- avoid double-counting holdings reported through included managers;
- preserve amendment metadata;
- document limitations where manager relationships cannot be fully de-duplicated.

Do not simply sum every filing row in a quarter.

Add tests for:

- original filing
- full amendment
- partial amendment
- duplicate accession
- late amendment
- same manager filing twice
- included-manager metadata

====================================================================
SECURITY IDENTIFIER MAPPING
====================================================================

The most important implementation risk is mapping 13F securities to VCP Trader
symbols.

Do not map solely by issuer-name string matching.

Preferred mapping hierarchy:

1. Exact CUSIP mapping already present in the internal security master.
2. Exact FIGI mapping when both sources provide FIGI.
3. Previously reviewed durable mapping.
4. Deterministic issuer/class match only when unique and high-confidence.
5. Unmapped.

Every mapping must record:

- mapping method
- mapped symbol
- confidence/status
- created at
- last verified at
- source identifiers

Suggested statuses:

- exact
- reviewed
- probable
- ambiguous
- unmapped
- rejected

Production analytics may use only:

- exact
- reviewed

Optionally allow probable mappings in an internal diagnostic view, never silently in
user-visible totals.

If the repository lacks reliable CUSIP/ticker mapping:

- implement the mapping architecture;
- populate only mappings that can be verified from existing approved data;
- return CONDITIONAL_GO;
- do not create guessed mappings for the entire market.

For the initial VCP Trader tracked universe, a controlled reviewed mapping table is
acceptable if it is auditable and versioned.

====================================================================
INGESTION DESIGN
====================================================================

Create a bounded background ingestion workflow.

Suggested cadence:

- check for a new SEC quarterly dataset daily during filing season;
- ingest each available quarter once;
- process amendments incrementally;
- allow an authenticated/admin manual run;
- never perform bulk ingestion during ordinary page requests.

Use:

- PostgreSQL advisory lock
- idempotent upserts
- structured ingestion status
- retries
- bounded concurrency
- resumable checkpoints
- retention of run metadata

Do not block application startup while downloading or processing a large quarter.

Startup may schedule the job asynchronously.

Required statuses:

- pending
- running
- completed
- partial
- failed
- skipped_locked
- skipped_disabled

NORMALIZATION RULES
====================================================================

- CUSIP formatting
- issuer whitespace
- class-title whitespace
- dates
- values and shares
- put/call values
- amendment flags

QUARTERLY AGGREGATION
====================================================================

For each mapped symbol and period of report, calculate:

- reportingManagerCount
- aggregateReportedShares
- aggregateReportedValue
- previousQuarterReportedShares
- previousQuarterReportedValue
- reportedSharesChange
- reportedSharesChangePercent, when denominator is valid
- newPositionManagerCount
- increasedPositionManagerCount
- reducedPositionManagerCount
- exitedPositionManagerCount
- unchangedManagerCount
- topHolderShareOfReportedShares
- top5HolderShareOfReportedShares
- top10HolderShareOfReportedShares
- largest reported holders
- coverage status
- amendment status
- generated at

Definitions must be documented.

“New position” means:

- manager has positive eligible shares this quarter;
- no eligible position for the same mapped security in the immediately previous
  comparable quarter.

“Exit” means:

- manager had a positive eligible position in the prior comparable quarter;
- no eligible position in the current effective filing set.

Do not infer intraperiod transactions.

====================================================================
INSTITUTIONAL EVIDENCE ALIGNMENT
====================================================================

Integrate institutional context into the existing Evidence Engine additively.

Possible states:

- Supports
- Neutral
- Weakens
- Unavailable

Use deterministic rules only.

Example principles:

Supports:
- eligible reported shares increased;
- increasing managers meaningfully exceed reducing managers;
- coverage is adequate;
- no unresolved amendment/mapping issue.

Weakens:
- eligible reported shares decreased;
- reducers/exits meaningfully exceed increasers/new positions;
- coverage is adequate.

Neutral:
- small change or mixed manager activity.

Unavailable:
- missing quarter;
- inadequate mapping;
- only one quarter;
- ingestion failure;
- unresolved amendments.

Do not change existing global evidence-score formulas without a separate explicit
review.

Institutional evidence should not dominate technical qualification.
