======================================================================
OBJECTIVE
======================================================================

Create a deterministic Institutional Signal Engine that transforms available,
mapped public SEC Form 13F holdings into concise, explainable institutional
research evidence for a ticker.

This engine will eventually feed:

- Opportunity Ranking Engine
- AI Trading Workspace
- Dashboard
- VCP AI

But DO NOT integrate those consumers during this sprint.

This sprint builds ONLY the canonical Institutional Signal Engine and its API.

No LLM scoring.
No predictions.
No personalized investment advice.
No "smart money" terminology.

======================================================================
3. QUARTER SELECTION
======================================================================

This is critical.

Do NOT compare SEC ZIP publication windows.

Compare actual period-of-report quarters.

Determine:

latest usable comparable holdings quarter

versus

previous usable comparable holdings quarter.

Example:

2026-Q1
vs
2025-Q4

Only use quarters whose persisted data passes the existing readiness/reconciliation
requirements.

If only one usable quarter exists:

status = "insufficient_history"
score = null

Still return whatever single-quarter descriptive evidence is safe to expose.

======================================================================
4. SECURITY MAPPING RULES
======================================================================

Use mappings from security_master / canonical mapping layer.

Do not require 100% global mapping coverage.

For ticker X:

calculate signal from reliably mapped holdings belonging to ticker X.

Track mapping coverage separately.

Do NOT guess ticker mappings inside this signal engine.

Do NOT perform fuzzy issuer matching here.

Mapping belongs to Sprint 2.2.5 / future mapping automation backlog.

If mapping quality is insufficient for the requested ticker:

status = "mapping_incomplete"
score = null

Return useful diagnostics but no false precision.

original filing

======================================================================
6. MANAGER-LEVEL CHANGE CLASSIFICATION
======================================================================

Compare each manager between previous and latest comparable quarters.

Deterministic rules:

previous = 0 AND latest > 0
→ NEW

previous > 0 AND latest = 0
→ EXITED

latest > previous
→ INCREASED

latest < previous
→ REDUCED

latest = previous
→ UNCHANGED

Create a reusable type:

InstitutionalManagerChange

Suggested fields:

managerName
previousShares
latestShares
shareChange
shareChangePct
previousValue
latestValue
valueChange
changeType

Do not expose internal implementation IDs in public API unless needed.

======================================================================
10. DETERMINISTIC INSTITUTIONAL SCORE
======================================================================

Create an explainable 0–100 Institutional Evidence Score.

IMPORTANT:

The score represents strength/direction of reported institutional ownership activity.

It does NOT represent:

stock quality
expected return
probability of price appreciation
buy/sell recommendation.

No AI.

Build score from transparent components.

Suggested conceptual components:

A. Breadth
- increasing managers vs reducing managers

B. Accumulation
- aggregate reported position/share change

C. Entrants vs exits
- new managers relative to exited managers

D. Concentration context
- broadening vs highly concentrated activity

E. Data quality
- mapping/comparable coverage

Choose final weights only after inspecting available data.

Requirements:

- total score 0–100
- every component individually exposed
- deterministic
- bounded
- unit tested
- missing evidence must not silently become neutral evidence
- insufficient quality → score = null

Do not let the data-quality component manufacture a directional signal.
