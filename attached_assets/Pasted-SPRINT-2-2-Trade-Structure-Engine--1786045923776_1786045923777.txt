SPRINT 2.2 — Trade Structure Engine

====================================================================
OBJECTIVE
====================================================================

Build the Trade Structure Engine.

This engine converts a completed Research Package into one or more
deterministic trade structures.

This sprint DOES NOT execute trades.

This sprint DOES NOT resolve live option contracts.

This sprint determines HOW a trader could express an investment thesis.

The output must work for users with or without a connected broker.

Everything produced is educational research and trade planning.

Never fabricate option contracts.

Never fabricate premiums.

Never fabricate Greeks.

Never fabricate bid/ask prices.

====================================================================
DO NOT MODIFY
====================================================================

Do NOT modify

• Opportunity Engine
• MCP
• Scanner
• PostgreSQL
• MarketHistoryService
• Broker abstraction
• Existing APIs
• Database schema
• Research Package
• Decision Engine

Reuse all existing deterministic outputs.

====================================================================
SUCCESS CRITERIA
====================================================================

Given any completed Research Package the platform should answer

1. What is the best stock structure?

2. What is the best options structure?

3. Why?

4. What DTE range is appropriate?

5. What strike selection approach is appropriate?

6. What are the trade-offs?

7. How does this compare with alternative structures?

8. How does the user proceed to InstaTrade™?

No infrastructure changes.

No database changes.

No new APIs.

No broker execution.

Return a detailed completion report listing

• Existing APIs reused
• Deterministic rules implemented
• Tests added
• Acceptance criteria verification
