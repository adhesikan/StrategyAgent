Repository:
VCP Trader AI / StrategyAgent

ROADMAP DISCIPLINE

This sprint is the FIRST sprint in Portfolio Research Intelligence.

Do NOT implement:

- screenshot ingestion
- PDF statement ingestion
- new broker integrations
- portfolio recommendations
- buy/sell instructions
- rebalancing advice
- agents / loops / graphs
- AI portfolio commentary

Those belong to later planned sprints.

============================================================
OBJECTIVE
============================================================

Build the canonical Portfolio Research data model and allow users to create/import
a portfolio WITHOUT requiring a brokerage connection.

Supported in THIS sprint:

1. CSV import
2. XLSX import
3. Manual position entry
4. Existing broker positions only if already available in current architecture

All input methods must normalize into ONE canonical portfolio model.

============================================================
10. DATA REFRESH POLICY
============================================================

Follow the platform principle:

EXTERNAL PROVIDERS ARE INGESTION SOURCES, NOT DEFAULT READ PATHS.

For imported positions:

do not call Twelve Data repeatedly for static portfolio fields.

Use existing stored/cached market data.

If latest quote must be fetched:

reuse current market-data service/cache.

Do not create a portfolio-specific Twelve Data path.

============================================================
11. USER ISOLATION
============================================================

Portfolio data is private.

Require:

authenticated user
userId ownership on every portfolio read/write
no cross-user access
no predictable portfolio ID exposure without ownership check
no broker credentials returned

Add explicit authorization tests.

============================================================
12. IMPORT SAFETY
============================================================

Spreadsheet files may contain malformed content.

Requirements:

file size limit
allowed MIME/type checks
row limit
formula cells treated safely
no macro execution
no arbitrary file execution
no path traversal
temporary uploads cleaned up
