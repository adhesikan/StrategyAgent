Sprint 2.1.3 – Research Decision Engine

Objective

Build an explainable institutional-quality Research Decision Engine.

IMPORTANT

DO NOT modify:

- Opportunity Engine
- MCP
- Scanner
- PostgreSQL
- MarketHistoryService
- Broker abstraction
- Existing APIs
- Database schema

This sprint is UI and orchestration only.

Reuse existing deterministic outputs.

====================================================

The research page should answer these questions:

1. Why did this qualify?

2. Why did it rank this high?

3. What supports the thesis?

4. What weakens the thesis?

5. What would invalidate it?

6. What would improve its score?
