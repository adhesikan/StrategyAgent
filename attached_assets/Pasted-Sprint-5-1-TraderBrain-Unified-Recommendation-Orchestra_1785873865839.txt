Sprint 5.1 — TraderBrain Unified Recommendation Orchestration

Goal

Complete the migration from legacy callOpenAi recommendation flows to TraderBrain.

TraderBrain should become the single orchestration engine for every recommendation request.

Do NOT modify:

• scanner algorithms
• ranking engine
• recommendation engine
• portfolio engine
• MCP tools
• execution logic
• broker integration

Reuse all existing deterministic services exactly as they are.
