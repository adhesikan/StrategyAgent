==================================================
CURRENT VERIFIED STATE
==================================================

Production GET /api/dashboard currently returns:

marketSnapshot.dataMode = "live"
marketSnapshot.dataSource = "twelve_data"

but:

opportunities.dataMode = "simulated"
candidate.dataMode = "simulated"

The opportunity candidates include a mixture of:

- real Twelve Data underlying stock price/history
- real or current sentiment context
- simulated strategy selection
- simulated options strikes
- simulated expiration
- simulated premium
- simulated open interest
- simulated options volume
- simulated bid/ask spreads
- simulated capital and payoff values

The production dashboard must not present this mixed payload as real current opportunities.

The MCP service already has deterministic scan and ranking tools and obtains market data through authenticated VCP Trader internal endpoints.

==================================================
GOAL
==================================================

Build a truthful production opportunity pipeline with two explicitly separate outputs:

1. REAL STOCK OPPORTUNITIES

Derived from:

- Twelve Data-backed market history
- deterministic MCP scanners
- deterministic qualification
- deterministic ranking
- supported sentiment and event context

2. OPTIONS AVAILABILITY

Without a supported live options provider or broker chain:

- no current contract candidates
- no synthetic contract metrics in the real opportunity list
- estimated strategy concepts may exist only in a clearly separate educational/estimated section

A disconnected broker must not prevent real stock opportunity discovery.

==================================================
3. REAL STOCK OPPORTUNITY SOURCE
==================================================

Use this production flow:

Twelve Data-backed VCP Trader market history
→ authenticated internal market endpoint
→ MCP deterministic scanners and/or rank_market_trade_candidates
→ validated VCP Trader adapter
→ dashboard stock opportunities

Reuse the same trusted validation and presentation contracts already used by Ask AI market-wide ranking.

Do not use OpenAI to:

- generate candidates
- rank candidates
- change qualification
- change status
- invent missing candidates

OpenAI availability or API-credit exhaustion must not affect deterministic dashboard opportunities.

==================================================
4. STOCK CANDIDATE FIELDS
==================================================

For each real stock candidate, display only supported deterministic fields such as:

- symbol
- company name when available from a trusted mapping
- strategy display name
- direction
- qualification status
- deterministic score or confidence
- setup state
- trigger or confirmation level when validated
- invalidation/risk reference when validated
- objective only when independently meaningful
- concise deterministic reason
- warnings
- earnings/event risk
- source timestamp
- data-quality label

Do not carry over simulated scenario fields such as:

- generated premium
- synthetic expiration
- synthetic strikes
- synthetic open interest
- synthetic options volume
- synthetic bid/ask spread
- synthetic maximum gain
- synthetic options breakeven
- synthetic contract liquidity claims

==================================================
5. OPTIONS BOUNDARY
==================================================

When no supported live options chain is available:

optionsAvailability must clearly report:

Live options chain unavailable

Connect a supported broker for current contracts, premiums, Greeks, liquidity and broker-ready order review.

An estimated options section may show only broad strategy concepts already supported by the deterministic recommendation engine, such as:

- long call concept
- debit spread concept
- covered-call concept
- cash-secured-put concept
- approximate DTE range
- defined-risk versus undefined-risk characteristics

It must be labeled:

Estimated structure — no live options chain used

Never display invented contract details.

Never place estimated options structures inside:

Today’s Real Market Opportunities
