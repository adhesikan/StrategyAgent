TASK 20 — External API Consumer Demo

Objective:
Prove that the Institutional Intelligence and Multibagger modules can be
consumed by a completely separate application using only the public /api/v1 API.

IMPORTANT:
Do NOT import StockMetrics server-side analytics services directly into this demo.
Do NOT connect directly to the StockMetrics database.
Do NOT duplicate institutional or multibagger calculations in the demo.

The demo must behave like a real external third-party application.

--------------------------------------------------
PART 1 — DEMO APPLICATION ARCHITECTURE
--------------------------------------------------

Create a small standalone external-consumer demo in a clean isolated location,
for example:

examples/institutional-api-demo/

or another repository-consistent location.

The demo should have:

Browser UI
   ↓
Demo backend / proxy
   ↓
StockMetrics public /api/v1
   ↓
Institutional Intelligence / Multibagger services

The browser must NEVER call StockMetrics with a privileged API key directly.

The demo backend must store the API key in an environment variable such as:

STOCKMETRICS_API_KEY

Also support a configurable API base URL:

STOCKMETRICS_API_BASE_URL

Do not hardcode production URLs.

--------------------------------------------------
PART 5 — SECURE API PROXY
--------------------------------------------------

Implement backend proxy routes in the demo.

Requirements:

1. Read STOCKMETRICS_API_KEY from server-side environment.
2. Send:

Authorization: Bearer <key>

to StockMetrics.

3. Never expose the key to browser JavaScript.
4. Never log the full key.
5. Never return the key in an error response.
6. Validate user-supplied path/query input before proxying.
7. Only allow explicitly approved StockMetrics API routes.
8. Do not implement an unrestricted generic proxy.

Example allowed proxy mappings:

/demo-api/institutional/accumulation
→ /api/v1/institutional/trends/accumulation

/demo-api/institutional/stocks/:symbol
→ /api/v1/institutional/stocks/:symbol

/demo-api/institutional/stocks/:symbol/trend
→ /api/v1/institutional/stocks/:symbol/trend

/demo-api/multibagger
→ /api/v1/multibagger/screener

/demo-api/multibagger/:symbol
→ /api/v1/multibagger/:symbol
