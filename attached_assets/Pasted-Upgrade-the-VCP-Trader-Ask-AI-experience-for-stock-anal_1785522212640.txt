"Analyze MU"
"Analyze NVDA"
"How does CRDO look?"
"Evaluate AVGO"

This task is about improving how Ask AI interprets and presents the existing analysis.

==================================================
GOAL
==================================================

Transform "Analyze <ticker>" from a generic AI paragraph into a concise, professional trading-research analysis.

The response should help the user quickly understand:

1. What is happening?
2. Is there a valid VCP setup?
3. Why or why not?
4. What technical structure currently exists?
5. What would need to happen for the setup to improve?
6. What levels/conditions should the user watch?

The AI should behave like a research analyst, not merely summarize indicators.

Do NOT provide personalized financial advice or tell the user to buy/sell.

==================================================

==================================================

For stock-analysis intent with a successful scan_vcp result, organize the analysis approximately as:

[TICKER] — Technical & VCP Analysis

Market Snapshot

Why the Setup Passes/Fails
What Would Improve the Setup
Levels / Conditions to Watch
Overall Assessment

The existing frontend response contract may constrain exact formatting.

Inspect the existing response schema and UI first.

Preserve backward compatibility.

Prefer adding structured fields to the existing response rather than embedding Markdown that the UI cannot reliably render.

3. VCP STRUCTURE
==================================================

Use the expanded scan_vcp result.

Show when available:

Stage
Base status
Base depth
Base duration
Contraction sequence
Volatility compression
Volume contraction
Higher-low structure
Actionable pivot
Distance to actionable pivot
Major historical high

Example for MU:

VCP Structure

Stage: No setup
Base: No confirmed base
Contractions: No valid tightening sequence
Volatility: Not sufficiently compressed
Volume: Contracting 19%
Higher lows: Not established
Actionable pivot: None
Major high: $1,255 — historical context only

CRITICAL:

majorHigh is historical context.

NEVER call majorHigh:
- pivot
- breakout level
- buy point
- entry
- resistance that must be broken to trigger a trade

Only actionablePivot represents a valid VCP pivot.

When:

actionablePivot.detected === false

or:

actionablePivot.price === null

show:

Actionable pivot: None

This is valid analysis, not missing data.

==================================================
4. WHY THE SETUP PASSES OR FAILS
==================================================

Use scanner factors, reasons, warnings and structural fields.

For a weak setup, explain the primary deficiencies.

Example:

Why it currently fails VCP

• Price is below important trend averages
• No confirmed consolidation base
• Recent pullback remains too deep
• Contractions are not tightening sufficiently
• Higher-low structure is not established
• No actionable pivot exists

For a strong setup:

Why it qualifies

• Established uptrend
• Successive contractions are tightening
• Volatility is compressing
• Volume is drying up
• Higher lows are established
• Price is approaching a valid actionable pivot

Do not invent reasons.

Use only information supported by scan_vcp and existing market context.

Prioritize the 3–6 most important factors instead of dumping every scanner field.

==================================================
5. WHAT WOULD IMPROVE THE SETUP
==================================================

This is an important new capability.

For weak/developing setups, explain what structural changes would improve the VCP setup.

Derive this deterministically from scanner state where possible.

Examples:

If no base:
"MU first needs to establish a stable consolidation base rather than continue making large directional swings."

If contractions are not tightening:
"Successive pullbacks would need to become progressively shallower."

If volatility compression is missing:
"Daily ranges and ATR should begin contracting."

If volume contraction is missing:
"Volume should generally decline as the consolidation tightens."

If higher lows are missing:
"The structure would improve if subsequent pullbacks hold above prior swing lows."

If trend is weak/downtrend:
"Price would need to repair the trend structure and regain important moving averages."

If actionable pivot does not exist:
"A valid pivot should only emerge after a base and tightening contraction structure form."

If price is far from a valid pivot:
"The setup may be developing, but price remains too far from the actionable pivot to be considered pivot-ready."

Do NOT invent future price targets.

Do NOT say the stock "will" improve if these occur.

Frame these as conditions that would improve the technical setup.

==================================================
6. CONDITIONS / LEVELS TO WATCH
==================================================

Create a concise monitoring section.

Use actual available scanner/context data.

Examples:

Conditions to watch

Trend repair:
Price regains relevant moving averages and their slopes improve.

Base formation:
Price establishes a controlled consolidation range.

Contraction quality:
Pullbacks become progressively shallower.

Volume:
Trading activity dries up during consolidation.

Pivot:
No actionable pivot exists yet; wait for the structure to establish one.

When a valid actionablePivot exists:

Actionable pivot: $XXX
Distance: X.X%

When a base exists:

Base support: $XXX
Base resistance: $XXX

Do not manufacture support/resistance when those fields are unavailable.

==================================================
7. STAGE-SPECIFIC ANALYSIS
==================================================

Use the scanner stages:

no-setup
early
developing
contraction
pivot-ready

Tailor the analysis accordingly.

NO-SETUP

Focus on:
- why structure fails
- what must repair
- do not present an entry level

EARLY

Focus on:
- emerging base
- what structural evidence is still missing

DEVELOPING

Focus on:
- existing base
- contraction progression
- trend/volume/volatility improvements needed

CONTRACTION

Focus on:
- tightening structure
- volume/volatility behavior
- proximity to potential actionable pivot

PIVOT-READY

Focus on:
- actionable pivot
- distance to pivot
- quality of contraction sequence
- trend confirmation
- volume/volatility characteristics

A high score alone must NEVER imply pivot-ready.

8. OVERALL ASSESSMENT
==================================================

Replace generic statements such as:

"The stock may continue to decline."

with a more useful structural assessment.

Weak example:

"MU currently lacks the structural characteristics of a valid VCP setup. The trend remains weak, no confirmed base has formed, and there is no actionable pivot. The setup becomes more interesting if price stabilizes, establishes a base, and subsequent pullbacks tighten on declining volatility and volume."

Strong example:

"NVDA has a mature VCP structure with tightening contractions, supportive trend characteristics and an identified actionable pivot. The key question is whether the structure remains tight as price approaches that level."

Avoid directional predictions unless clearly supported and appropriately qualified.

12. CONFIDENCE
==================================================

Review how confidence is generated.

Confidence should reflect data completeness and analytical agreement, NOT bullishness/bearishness.

For example:

high confidence:
live market context available + successful scan + consistent indicators

medium:
scan available but mixed structural evidence

low:
missing data, failed scan, insufficient history, conflicting inputs

Do not label a bearish conclusion as low confidence merely because it is bearish.

==================================================
13. FAILURE HANDLING
==================================================

Preserve current graceful fallback.

If scan_vcp fails:

- do not fabricate score
- do not fabricate pivot
- do not fabricate base
- clearly indicate VCP scanner data is temporarily unavailable
- continue using existing market context if available

If history is insufficient:

say that structural VCP analysis is limited by insufficient history.
