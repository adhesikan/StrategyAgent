docs/operations/46-broker-independence-architecture.md

============================================================
OBJECTIVE
============================================================

Perform a repository-wide inventory of every place VCP Trader AI currently:

- requires a brokerage connection
- checks brokerConnected / hasBrokerConnection
- gates a feature because broker data is absent
- returns FAIL/BLOCKED/UNAVAILABLE due to missing broker
- fetches research/planning data directly from Tradier or TradeStation
- assumes account/position/buying-power context exists
- suppresses UI elements when broker is disconnected

Every gate must be classified as:

BROKER_INDEPENDENT
BROKER_ENHANCED
BROKER_REQUIRED

Use the definitions in Doc 46.

DO NOT CHANGE APPLICATION CODE.
