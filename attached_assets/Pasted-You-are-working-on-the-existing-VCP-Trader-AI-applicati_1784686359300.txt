# Phase 4: Secure postMessage Handling

The trusted CongressFlow origin is:

https://congress.vcptrader.com

Create a centralized constant:

CONGRESSFLOW_ORIGIN=https://congress.vcptrader.com

When receiving events:

1. Verify:

   event.origin === "https://congress.vcptrader.com"

2. Verify:

   event.source === iframeRef.current?.contentWindow

3. Verify event.data is an object.

4. Verify event.data.type is a supported event type.

5. Validate required payload fields.

6. Ignore malformed or unknown events.

Do not process CongressFlow messages from any other origin.

Do not use "*" when validating incoming messages.

For outgoing messages, send to the explicit trusted origin:

iframe.contentWindow.postMessage(payload, CONGRESSFLOW_ORIGIN)

Do not send outgoing production messages using "*".

# Phase 5: Auto-Height Resizing

Listen for:

CONGRESSFLOW_HEIGHT_CHANGED

When received:

- Validate that height is a finite number.
- Reject negative, zero, NaN, infinite, or unrealistic heights.
- Clamp the value to configured boundaries.

Suggested defaults:

minHeight = 500
maxHeight = 2400

Apply:

iframe.style.height = `${clampedHeight}px`

Requirements:

- Use a smooth CSS height transition only if it does not create layout instability.
- Avoid rapid resize loops.
- Debounce or requestAnimationFrame updates if events arrive frequently.
- Keep a fallback height before the first height event.
- Full activity view may use a larger fallback, such as 700px.
- Ticker card may use a smaller fallback, such as 480px.
- Do not allow the iframe to collapse to zero height.
- Ensure mobile height updates work correctly.
